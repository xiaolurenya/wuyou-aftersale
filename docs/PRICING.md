# 价格与授权

「无忧商服通」为专有商业软件，采用一次性买断授权。公开仓库仅提供介绍文档、compose 模板与安装脚本，不包含核心源码。

## 购买与激活

1. 首次安装后可试用 15 天；到期提示窗口展示购买方式与联系方式。
2. 获取激活码后，在软件内按提示输入；激活采用 Ed25519 离线签名，断网环境可完成校验。
3. 公开仓库不提供真实微信号、二维码、购买网址或激活码示例。

## 激活码绑定设备与授权转移

- 激活码按安装设备绑定；更换 NAS、重装系统、更换数据盘或迁移部署前，建议先导出整机 JSON 备份并复制数据目录。
- 整机恢复至新设备后，授权状态会按目标设备重新初始化；需使用与目标设备匹配的激活码。
- 设备未变且沿用同一数据卷的升级或重装，通常无需重新付费。

退款、设备变更、授权转移及服务支持范围以正式购买说明为准。购买前需确认对应政策。

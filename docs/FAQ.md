# 常见问题（FAQ）

本文面向已安装或准备安装「无忧售后助手」的用户。涉及购买、激活码发放、设备变更与退款的规则，一律以作者说明为准（作者微信：待填写；备用联系方式：待填写）。安装步骤见 [安装说明](INSTALL.md)，价格见 [价格与授权](PRICING.md)。

## 1. 支持哪些 NAS？

目前支持飞牛 NAS、群晖 NAS、绿联 NAS，共同前提是设备能运行 Docker 与 Docker Compose。群晖建议使用 DSM 7 及以上并安装 Container Manager；飞牛、绿联需在系统应用中启用 Docker 相关功能，不同系统版本的菜单名称略有差异，以设备实际界面为准。其他能运行 Docker Compose 的设备是否可用，请咨询作者（联系方式：待填写）。

## 2. 端口 3650 能否修改？

可以。compose 文件里 `ports` 一行形如 `"3650:3650"`，冒号左边是宿主机端口、右边是容器端口；只改左边，例如改成 `"3651:3650"`，保存后执行 `docker compose up -d` 重建容器，再用 `http://设备IP:3651` 访问。改端口后需在 NAS 防火墙放行新端口，并通知局域网内使用者更新书签；示例配置见 [安装说明](INSTALL.md)。

## 3. 数据存在哪里？

数据保存在宿主机映射到容器的数据卷目录里，例如 `/vol1/docker/aftersale`（通用示例，请以安装时实际填写的路径为准；群晖常见为 `/volume1/docker/aftersale` 一类路径）。容器本身可以随时重建，只要不删除该目录，登记资料、后台基础资料与账号信息都会保留。建议把该目录放在 NAS 的持久化存储，而不是临时目录。

## 4. 突然断电会不会丢数据？

已经保存的单据写在数据卷上，恢复供电后 NAS 与 Docker 会按 compose 的重启策略重新拉起服务，用原地址登录即可看到原有数据；正在填写但尚未提交保存的那一条登记可能需要重新录入。建议为 NAS 接 UPS，并开启系统提供的自动备份与定期导出。

## 5. 断网能不能用？

可以。系统部署在局域网内的 NAS 上，浏览器访问不依赖公网；激活校验采用 Ed25519 离线签名，断网环境也能完成校验。需要联网的环节主要是首次获取激活码、联系作者、购买以及下载新版本镜像。

## 6. 激活码换设备或重装系统怎么办？

激活码按安装设备绑定，具体绑定方式、解绑次数与重发规则以作者说明为准（见 [价格与授权](PRICING.md)）。更换 NAS、重装系统或更换数据盘之前，建议先导出一份 xlsx / CSV / JSON 全量备份并复制数据卷目录，再联系作者（作者微信：待填写）确认转移方式。若设备未变且仍使用同一数据卷，通常无需重新激活；如界面提示需要重新激活，请联系作者处理。

## 7. 试用 15 天到期后，数据会不会没？

不会。到期限制的是继续使用相关功能，已有登记数据仍保存在数据卷中；输入有效激活码后可继续正常使用。为稳妥起见，建议在到期前按第 12 条导出一次全量备份。

## 8. 后续升级要不要再付钱？

不需要。199 元为一次性买断，之后所有版本更新永久免费。升级时只需拉取新镜像并重建容器，保持数据卷目录不动，激活码继续有效；详细步骤见 [安装说明](INSTALL.md) 的「升级」一节。

## 9. Excel / CSV 导入时表头怎么认？

导入时会自动识别中英文表头，例如「产品型号 / Product Model」「序列号 / Serial Number」「登记日期 / Registration Date」这类常见写法。导入前会先展示预览页并要求确认字段映射；自动识别不确定时，可在预览页手动指定每一列对应的字段。建议先用少量数据试导入一次，确认映射无误后再导全量。

## 10. 序列号怎么批量录入？

在前台登记页的序列号 / 条码输入框中，可一次粘贴多行文本（每行一个序列号），也可用条码枪连续扫描逐台录入；一单多台会保存在同一张登记单下。查询页同样支持批量粘贴多个序列号做精确匹配查询，适合到货核对。

## 11. 四级权限怎么分？

系统内置超级管理员、管理员、登记员、只读四级角色：超级管理员拥有全部管理与账号权限；管理员负责后台基础资料维护与日常单据管理；登记员主要用于前台登记与查询；只读角色仅可查看，不能修改数据。各角色的具体可操作项以软件内角色说明为准。建议为每位使用者分配独立账号，配合操作日志便于追溯。

## 12. 怎么备份？

两种做法建议同时用：一是在系统内导出 xlsx / CSV / JSON 全量备份，并把文件另存到 NAS 其他目录或外部存储；二是定期复制或打包数据卷目录（示例 `/vol1/docker/aftersale`，按实际路径改），最好在复制前先停止容器，避免写入中的文件不一致。系统另提供自动备份，具体周期与保留份数以系统设置为准。恢复时用备份文件导入，或把数据卷目录放回原路径后重建容器。

## 13. 忘记密码怎么办？

密码不提供明文回显，只能重置、不能查看。若还有超级管理员或管理员账号能登录，由该账号在后台为对应账号重置密码；若所有管理员密码都遗失，请联系作者（联系方式：待填写）获取处理方式。请勿通过删除数据卷来「重置」，那样会连带删除业务数据；先按第 12 条备份再操作。

## 14. 能不能多人同时使用？

可以。局域网内多台电脑或平板通过浏览器访问同一地址（默认 `http://设备IP:3650`），按各自账号登录后并行登记、查询与导出；权限由账号角色决定，操作日志会记录各自的关键操作。实际可承载的同时在线人数取决于 NAS 性能与局域网状况，建议按岗位分配独立账号，而不是共用同一账号。

## 15. 试用 15 天从什么时候开始算？

自首次安装并启动服务开始计算，到期后登录界面会弹出激活提示窗口，窗口内展示作者微信二维码与联系方式（占位：待填写）。试用期内功能与正式版一致，可先完成导入与试登记再决定是否购买；具体计时口径以软件内提示为准。

## 16. 导入出现错误行回执怎么处理？

导入结束后会给出错误行回执，标明未通过的行及原因（如表头未匹配、必填字段为空、日期或数量格式不符）。按提示在源文件中修正这些行后重新导入即可；为避免重复建档，建议把错误行另存为新文件后再导入，而不是把整份原文件再导一次。

## 17. 换新和返回信息怎么登记？

登记单上可勾选换新标记并填写换新序列号；设备返回后补填返回日期与送修 / 返回快递单号。维修进度按状态机逐步流转，系统会保留进度时间线，便于回看每一次变更；换新标记也可作为查询条件单独筛选。

## 18. 怎么查某一台机器或某个时间段？

在查询页可按字段精准组合条件：序列号支持精确匹配与批量粘贴，快递单号可按送修 / 返回单号查，登记日期、销售日期、返回日期支持日期区间，换新标记可单独筛选。多个条件可叠加使用，缩小到具体单据后再导出或核对。

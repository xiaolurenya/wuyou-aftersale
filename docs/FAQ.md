# 常见问题

本文档汇总部署、账号、数据、授权与日常使用中的常见问题。购买、激活码发放、设备变更与服务支持规则以正式购买说明为准。

## 1. 支持哪些 NAS？

支持飞牛 NAS、群晖 NAS、绿联 NAS，以及可运行 Docker Compose v2 的 Ubuntu / Debian 服务器、宝塔面板与云端主机。

## 2. 端口 3650 能否修改？

可以。compose 中 `ports` 左侧为宿主端口，右侧为容器端口。修改为 `"3651:3650"` 后，访问地址同步变为 `http://设备IP:3651`，并需放行对应防火墙端口。

## 3. 数据保存在哪里？

数据保存在宿主机 `./data:/app/data` 映射目录；备份保存在 `./backups:/app/backups`。容器可重建，数据目录不得删除。

## 4. 异常断电是否会导致数据丢失？

已提交的数据写入持久化数据卷。设备恢复供电后，服务按 `restart: unless-stopped` 策略拉起；未提交的表单内容需重新录入。建议为 NAS 配置 UPS，并定期导出整机 JSON 备份。

## 5. 断网环境能否使用？

局域网访问与激活码离线校验不依赖公网。联网主要用于首次获取激活码、联系服务方与拉取新版本镜像。

## 6. 激活码换设备或重装系统如何处理？

激活码按安装设备绑定。更换 NAS、重装系统或更换数据盘前，应导出整机 JSON 备份并复制数据目录，再向服务方确认授权转移方式。整机恢复至新设备后，授权状态会按目标设备重新初始化。

## 7. 试用 15 天到期后，数据是否会清除？

不会。到期后限制继续写入相关功能，已有数据仍保存在数据卷中；输入有效激活码后恢复完整功能。建议在到期前导出整机 JSON 备份。

## 8. 后续升级是否再次收费？

不收费。299 元为一次性买断价格，后续所有版本更新免费。升级时保持数据目录不变，激活码继续有效。

## 9. Excel / CSV 导入如何识别表头？

导入流程支持中英文常见表头识别，并提供预览与字段映射确认。字段无法自动匹配时，可在预览页面手动指定列对应关系。建议先以少量数据试导入。

## 10. 序列号如何批量录入？

前台登记页支持多行粘贴与扫码枪连续扫描；一单多台会归入同一登记单。任意检索同样支持批量粘贴序列号进行精确匹配。

## 11. 四级权限如何划分？

超级管理员拥有全部管理与账号权限；管理员负责基础资料维护与日常单据管理；登记员用于前台登记与查询；只读角色仅可查看。各角色权限点可在后台配置。

## 12. 如何备份？

建议同时采用系统内整机 JSON 备份与目录级复制。整机 JSON 覆盖售后单、字典、用户、设置、安心保、报修单、取件记录、报价商品与渠道账号；目录级复制覆盖 SQLite、设备指纹、会话密钥与自动备份文件。

## 13. 忘记密码如何处理？

密码不提供明文回显。存在可登录的管理员账号时，在后台为对应账号重置密码；所有管理员密码均遗失时，需联系服务方处理。不得通过删除数据目录重置密码。

## 14. 是否支持多人同时使用？

支持。局域网内多台设备通过浏览器访问同一地址并按各自账号登录，权限由账号角色决定，关键操作写入审计日志。

## 15. 试用 15 天从何时开始？

自首次安装并启动服务开始计算；到期后登录界面展示激活提示与购买方式。试用期内功能与正式版一致。

## 16. 导入错误行如何处理？

导入结束后系统给出错误行回执与原因。按提示修正源文件后重新导入；为避免重复建档，建议仅导入修正后的错误行文件。

## 17. 收件后的维保和返回怎么登记？

前台快捷登记只负责收件，默认状态为「已收件」。在左侧「维保中心」选择送修上家或自维保，填写客户寄来单号、快递单号 / 快递公司、寄商家备注和送修信息。设备返回后通过「返回录入」提交为已返回，之后才会进入「客户取件」。旧的换新与返回信息不再放在登记页。

## 18. 如何查询指定设备或日期区间？

任意检索支持序列号精确匹配与批量粘贴，支持客户、型号、上家、联系人、快递单号、登记日期、销售日期、返回日期、自费信息、取件信息和完整维保备注组合查询。多个条件可叠加使用；快递单号列后显示「自费」列，完整维保信息集中展示在快递单号单元格，便于一处核对。

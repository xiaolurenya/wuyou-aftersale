# 无忧售后助手

面向售后登记场景的商用管理软件，私有部署在飞牛 NAS / 群晖 NAS / 绿联 NAS，通过浏览器在局域网内使用。

![版本](https://img.shields.io/badge/version-v1.0.0-blue)
![许可](https://img.shields.io/badge/license-Proprietary-orange)
![端口](https://img.shields.io/badge/port-3650-green)
![平台](https://img.shields.io/badge/platform-Feiniu%20%2F%20Synology%20%2F%20UGREEN-lightgrey)

> 支持平台：飞牛 NAS、群晖 NAS、绿联 NAS；宿主端口 3650；一次性买断，后续版本更新永久免费。

## 功能概览

### 前台登记

| 能力 | 说明 |
| --- | --- |
| 登录 | 首页使用账号密码登录 |
| 登记日期 | 自动填写当天日期 |
| 送修信息 | 寄送上家 / 售后站点、送修单位、联系人、联系方式 |
| 产品信息 | 产品型号、数量、销售日期、故障描述、备注 |
| 序列号 / 条码 | 支持一单多台、批量粘贴与条码枪录入 |
| 维修进度 | 状态机流转，并保留维修进度时间线 |
| 换新 | 换新标记与换新序列号 |
| 返回信息 | 返回日期、送修快递单号、返回快递单号 |
| 自动单号 | 按 AS-YYYYMMDD-#### 格式自动生成 |
| 随手建档 | 登记时可直接手动输入商品型号、上家（售后站点）与联系方式并自动建档 |
| 统计首页 | 首页提供业务统计概览 |

### 精准查询

| 能力 | 说明 |
| --- | --- |
| 组合查询 | 全部登记字段可按条件精准组合筛选 |
| 序列号 | 精确查询，支持批量粘贴多个序列号 |
| 快递单号 | 按送修 / 返回快递单号查询 |
| 日期区间 | 按登记日期、销售日期、返回日期等日期区间筛选 |
| 换新筛选 | 单独筛选带换新标记的单据 |

### 导入导出

| 能力 | 说明 |
| --- | --- |
| 本地导入 | Excel / CSV 文件本地导入 |
| 表头识别 | 自动识别中英文表头 |
| 映射确认 | 导入前预览并确认字段映射 |
| 错误行回执 | 输出错误行回执，便于修正后重新导入 |
| 导出备份 | 导出 xlsx / CSV / JSON，用于全量备份 |

### 后台与权限

| 能力 | 说明 |
| --- | --- |
| 基础资料 | 维护商品型号、上家（售后站点）、联系方式 |
| 人员权限 | 超级管理员 / 管理员 / 登记员 / 只读 四级角色 |
| 操作日志 | 记录关键操作，便于追溯 |

### 激活与授权

| 能力 | 说明 |
| --- | --- |
| 免费试用 | 首次安装可免费试用 15 天 |
| 到期激活 | 试用到期后需输入激活码，弹窗展示作者微信二维码与联系方式（占位：待填写） |
| 离线校验 | 激活采用 Ed25519 离线签名，断网环境下可用 |
| 买断升级 | 一次性付费，后续所有版本更新永久免费 |

其他能力：维修进度时间线、自动单号、统计首页、数据卷持久化与自动备份。

## 快速安装

> 交付镜像：`xiaoluya/wuyou-aftersale:1.0.0`（Docker Hub 公开，源码不公开）

前提：NAS 已可运行 Docker 与 Docker Compose。将作者提供的 compose 文件放入数据目录后执行：

```bash
docker compose up -d
```

- 访问地址：`http://设备IP:3650`
- 默认账号：待填写（以安装说明为准）；**首次登录后请立即修改默认密码**。
- 数据卷路径、首次登录与防火墙设置见 [安装说明](docs/INSTALL.md)。

> 镜像地址、默认账号等随软件提供的信息一律以作者提供的说明为准；本仓库不附带任何具体账号或激活信息。
